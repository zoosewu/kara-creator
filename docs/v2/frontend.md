# 前端（Svelte）

## 技術

- **Svelte 5 + Vite + TypeScript**，單頁應用（不用 SvelteKit 的伺服器端功能）
- `npm run build` 輸出到 `nas/internal/api/dist/`，Go 用 `go:embed` 內嵌；Node 只在開發與建置時需要，NAS 上不需要
- API 型別由 OpenAPI 產生（`openapi-typescript`），不手寫型別
- 狀態更新靠 SSE（`/api/v1/events`），不輪詢
- 不用 UI 元件庫；沿用 v1 `ui/static/style.css` 的設計（顏色變數、亮暗雙色、按鈕樣式）
- 介面文字一律繁體中文（台灣），沿用 v1 的用詞

## 設計原則（使用者的偏好，沿用 v1）

- 簡約、亮暗雙色（預設跟隨系統，右上角切換，記在 localStorage）
- **會啟動處理的按鈕**（藍色外框、播放圖示）和**只開畫面的連結**（灰色）要明顯區分
- 用字白話但不要太直白（例如「去人聲」「製作伴唱帶」）
- 手機也要能用（NAS 上最常見的情境是手機開網頁）

## 驗證

v1 的做法沿用：無頭瀏覽器（Chromium + DevTools 協定）開頁面、執行 JS 操作、截圖確認，而不只是看程式碼。
container 內用 Playwright（安裝前先問使用者）。截圖用測試曲庫（自己編的歌名與歌詞），不要用使用者真實的曲庫。
